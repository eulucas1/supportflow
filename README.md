# SupportFlow

Sistema de atendimento para empresas, com organização de chamados e colaboração entre administradores e atendentes.

## Estado atual

O projeto está na etapa de inicialização do repositório. Esta etapa inclui apenas este README e as regras básicas do `.gitignore`. Nenhuma funcionalidade da aplicação foi implementada; a stack e o escopo abaixo estão planejados.

## Escopo inicial planejado

- Cadastro, login e logout.
- Organizações com administradores e atendentes.
- Isolamento dos dados entre empresas.
- Chamados com responsável, prioridade e status.
- Comentários e histórico dos chamados.
- Busca, filtros e paginação.

## Stack planejada

- **Backend:** Python + FastAPI.
- **Frontend:** React + TypeScript.
- **Banco de dados:** PostgreSQL.
- **CI/CD:** GitHub Actions.

As aplicações, dependências, infraestrutura e rotinas de CI/CD ainda não foram criadas ou configuradas.
